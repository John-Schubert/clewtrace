# App shell demonstration

Verification method: Demonstration. Repeat before each release and whenever the shell,
the theme, or the action registry changes. Record the result below.

## Checklist

- [ ] Ctrl+Shift+P (Cmd+Shift+P on macOS) and Ctrl+K open the command palette.
- [ ] Typing filters the commands, the arrow keys move, Enter runs, Escape closes.
- [ ] Every button in the window has a matching command in the palette.
- [ ] With no stored choice, the window follows the OS light or dark setting, and changes
      when the OS setting changes while the app is open.
- [ ] "Theme: light" and "Theme: dark" override the OS setting and survive a restart.
- [ ] "Theme: follow the OS setting" returns to following the OS.

## Result

Not yet run on a built app. Run on Windows, macOS, and Linux at the next pre-release.
