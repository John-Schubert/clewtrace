# Contributing

Thank you for your interest in Clewtrace.

- **Bug reports and suggestions are welcome.** Open an issue with steps to reproduce, your
  operating system, and the Clewtrace version.
- **Outside code contributions are not accepted at this time** (CT-DEV-013). Pull requests
  from outside the project will be closed without review. This keeps licensing simple while
  Clewtrace is offered under the Business Source License.
- **Security issues:** please report privately through GitHub's security advisory feature
  for this repository rather than in a public issue.
